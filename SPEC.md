# AI Math Teacher & Study Platform Specification
Rules: Unattended mode, never ask questions, commit after each phase, ZERO emojis anywhere, never write robotic apologies like "I'm sorry", teach like a strict human Algebra 2/AP teacher, render all math with KaTeX, keep GEMINI_API_KEY server-only, verify every phase with `npx tsc --noEmit` and `npm run build`.

- Phase 1: Next.js 15 + TS + Tailwind + KaTeX (`react-katex`) + `mathjs` + `perfect-freehand` + Lucide icons. Collapsible sidebar + mobile bottom nav. Instant theme switcher with 5 themes (Clean Paper Light, Midnight Chalkboard Dark, Royal Violet Purple, Forest Sage Green, High-Contrast Exam) + Custom Color Picker persisted in `localStorage`.
- Phase 2: Guest mode (`localStorage` auto-migrated on login) + `@supabase/ssr` Email/Password & Google OAuth. `supabase/schema.sql` with RLS for `profiles` (`xp`, `level`, `streak_days`, `skill_mastery`), `folders`, `solutions`, and `practice_tests`. Saved History & Custom Folders page.
- Phase 3: Triple-Input Math Studio: (Tab 1) Image/screenshot drag-drop, `Ctrl/Cmd+V` clipboard paste, webcam, and interactive crop/rotate box; (Tab 2) Smooth freehand drawing canvas with pen sizes, colors, eraser, undo/redo, grid toggle; (Tab 3) Equation input with visual math symbol keypad + live KaTeX preview.
- Phase 4: `/api/solve` using `@google/genai` (`gemini-2.5-flash`) with 2-pass self-verification (solve step-by-step, verify every algebraic line and plug answer back in before returning JSON). Show: (a) Detected problem in KaTeX, (b) Prerequisite Skills Needed (explains foundational skills like integer factoring before polynomial factoring + embeds matching Khan Academy/YouTube lesson via `youtube-nocookie.com`), (c) Never-skip step-by-step teacher solution, (d) Verified Final Answer with copy button, (e) Simpler/Faster Way tab, (f) Challenge Me: Harder/Honors Version generator button, (g) Open in Graphing Calculator button.
- Phase 5: `/api/tutor` Socratic Teacher Chat programmed to argue back and push back respectfully whenever a student guesses wrong + quick quiz chips. Add "Spot the Teacher's Mistake" 60-second drill and Printable 1-Page Formula Cheat Sheet export.
- Phase 6: `/practice-test` Upload/paste 1-10 problem screenshots at once and generate an interactive & printable test at Same Level, Hard Level, or AP Level with auto-grading and step-by-step solutions. `/calculator` Desmos-style 2D graphing calculator with unlimited equations, auto-generated parameter sliders (`a, b, c`), clickable roots/extrema/intersections, table of values, and PNG export.
- Phase 7: `/videos` Khan/YouTube Topic Video Finder using AI + curated Khan Academy / Organic Chemistry Tutor / 3Blue1Brown video IDs (plus optional `YOUTUBE_API_KEY` if set, never required) with embedded player. Final `npx tsc --noEmit` and `npm run build` verification.
